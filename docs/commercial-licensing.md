# Kommerzielle Lizenzierung – Vorbereitung

> Interne Arbeitsunterlage. Es werden keine Gebühren und keine Vertragstexte festgelegt.

## Grundsatz
- Gewerbliche Nutzung ist **nur mit Einzelvertrag** erlaubt, auch die rein interne Nutzung.
- Es gibt **keine** öffentlich verwendbare kommerzielle Lizenz, die ohne Vertragsabschluss gilt.
- Der öffentliche Hinweis steht in [LICENSE-COMMERCIAL.md](../LICENSE-COMMERCIAL.md).

## Abgrenzung (Festlegung des Rechteinhabers)
| Nutzer | Lizenz |
|---|---|
| Eingetragener Verein (e.V.), Kompressor im Vereinsbetrieb | Community |
| Eingetragener Verein (e.V.), der Flaschen gegen Entgelt füllt | Community |
| Privatperson, eigener Kompressor, private Nutzung | Community |
| Nicht eingetragener Verein / Vereinigung ohne „e.V.“ | kommerziell |
| Einer Tauchschule angegliederter e.V. – Nutzung für den eigenen Vereinsbetrieb | Community |
| Betrieb über einen Verein für eine Tauchschule bzw. deren Geschäftsbetrieb (verdeckte gewerbliche Nutzung) | **nicht zulässig** (nur mit kommerzieller Lizenz der Tauchschule) |
| Tauchschule, Tauchshop, Tauchbasis (gewerblich) | kommerziell |
| Gewerblicher Füllstationsbetreiber, Dienstleister | kommerziell |
| Systemintegrator, der Kunden das System einrichtet | kommerziell (für die eigene gewerbliche Tätigkeit, auch wenn der Endkunde ein e.V. ist) |
| Hersteller / OEM | kommerziell (gesonderte OEM-Bedingungen) |
| Behörden, Feuerwehren, Hilfsorganisationen ohne e.V. | nach obiger Regel kommerziell; Ausnahme möglich, **zu entscheiden** |

## Vorzubereitende Vertragsbestandteile (für die rechtliche Ausarbeitung)
- Lizenzgegenstand, Version(en), Updates
- Nutzungsumfang: Standorte, Anzahl Kompressoren, interne Nutzung oder Kundenprojekte, Weitergabe/OEM
- Laufzeit, Kündigung, Vergütungsmodell (noch offen)
- Gewährleistung und Haftung (Sicherheitshinweise aus [DISCLAIMER.md](../DISCLAIMER.md) übernehmen; die Software ist kein Sicherheitssystem)
- Support und Wartung (optional, getrennt vereinbaren)
- Anwendbares Recht, Gerichtsstand
- Umgang mit Fremdkomponenten (deren Lizenzen bleiben unberührt)
